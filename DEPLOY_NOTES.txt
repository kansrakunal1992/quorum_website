5 files, all drop into the existing website Railway project root

WHAT'S NEW IN THIS UPDATE
--------------------------
1. FOUNDING_MEMBER_ENABLED env var (server.js, env.example)
   - Defaults to OPEN (true) if unset — nothing changes unless you set it.
   - Set FOUNDING_MEMBER_ENABLED=false in Railway → website project →
     Variables, then redeploy/restart, to close the cohort:
       - /kunal and /abhilash render WITHOUT the "Interested in becoming
         a Founding Member?" box — cards revert exactly to their state
         before this feature existed (verified: identical spacing).
       - /founding-member redirects (302) to /kunal instead of showing
         a live invite page with no real entry point into it.
       - Direct/bookmarked hits on the raw filenames (/card-kunal.html,
         /card-abhilash.html, /founding-member.html) now redirect (301)
         to the canonical short paths too, so the toggle can't be
         bypassed by hitting the raw file.
   - Flip it back to true (or unset it) to reopen the cohort — no code
     change needed either way.
   - This is a website-only visibility toggle. It does not touch the
     app's own seat-cap logic (lib/founding.ts / Mirror gate), which is
     the real source of truth for whether a seat can be sold.

2. founding-member.html — editorial revamp
   - ~30-40% less copy throughout, same structure and section order.
   - Protected lines kept verbatim: "You don't have to wait for Quorum
     to be finished. You can help decide what it becomes." and
     "Not everyone. Deliberately."
   - New section after the videos: "What happens next" — a plain
     4-step visual journey (bring a decision → experience free → Mirror
     builds your record → founding pricing becomes available) to remove
     uncertainty before asking for anything.
   - New short reflective section before the final CTA — one quiet,
     non-salesy beat ("Most tools are encountered fully formed...").
     No eyebrow/heading on it deliberately, so it reads differently
     from the informational sections around it.
   - Videos still appear before pricing; trust philosophy (experience
     before paying) preserved and, if anything, reinforced.
